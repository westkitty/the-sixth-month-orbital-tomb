# The Sixth Month R10 - One-command Mac launch

Download `THE_SIXTH_MONTH_ORBITAL_TOMB_R11.zip` to Downloads, then paste:

```sh
cd "$HOME/Downloads" && mkdir -p "Orbital-Tomb-R11" && unzip -n "THE_SIXTH_MONTH_ORBITAL_TOMB_R11.zip" -d "Orbital-Tomb-R11" && cd "Orbital-Tomb-R11/THE_SIXTH_MONTH_ORBITAL_TOMB_R11" && bash ./START_MAC.command
```

The launcher requires an active Internet connection for the initial dependency installation; it validates tests and build before opening localhost. If Node is missing, it can use existing Homebrew or explains how to install Node. It does not deploy or publish the project. Leave Terminal open while using the local server, Ctrl+C to stop.

Press **WATCH SEPARATIONS** + **▶**, select 0.1x–16x, and use **BRIGHTEN** for the best first experience.


Press **K** after selecting a real structural component to display its displacement from the original location. Press **K** again to hide the survey. Press **H** to hide UI and the R5 survey during the final room reveal. Switch off the pre-existing G/T original-geometry and route overlays separately if enabled.


## R7: Ride the physical fragment

While walking or floating close to a real station compartment, press **F** or ANCHOR / RELEASE. Move time forward and your camera stays attached to that actual reversible geometry, including its drift and angular tilt. Release to continue in free float. This is a modeled observer action, not a claim about a crew survivor. Original room coordinates remain fixed when using camera 4.

## R6: Witness a specific structural cut

Press **. (period)** or **NEXT CUT** to advance to the next one of six source-derived removal windows; press **, (comma)** or **PREV CUT** to replay the preceding window. The camera frames an actual separation joint, automatically plays forward at **0.5x**, and pauses at a meaningful active cut. This is not a historical archive of timestamps, only reversible model-driven inspection. Space or the standard time controls interrupt the special witness play; normal camera controls and original source inspections remain available.

## R8: Compare only the selected source component

Select a station component from the Structural Tracking selector or by clicking it from orbit. Toggle COMPARE, then ISOLATE SELECTED COMPARISON. Change the comparison month to see one structure at two modeled times instead of the whole superimposed station. Toggle again to restore the full comparison. This does not alter real geometry or historical source.

## R9: Touch inspection and recovery

In the ORBIT camera, drag **one finger** to rotate around Meridian. Pinch **two fingers** to zoom in/out; if one finger leaves, the remaining touch resumes rotation without jumping. A pinch never selects a structure or triggers mouse pointer lock. The manual orbit wheel and keyboard controls remain unchanged.

## R10 new instruments

After entering Meridian, inspect evidence with I; in CONTROLS select EVIDENCE RELATIONSHIPS to test conclusions. Markers Y = provenance source layer. SCALE REVEAL moves the viewing camera from a room to orbit. PACED WITNESS pauses before and after an existing cut. The entry screen offers a quiet first look (H restores controls). All systems are reconstructive; none transmits crew records or introduces canon.
