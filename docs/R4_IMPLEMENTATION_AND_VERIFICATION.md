- `src/save-model.ts`: source-bounded discovery persistence while retaining the existing save schema and compatibility.

- `public/sw.js`: new cache version; no new remote asset dependencies.
- `tsconfig.test.json`, `tests/forensic.test.mjs`: new test coverage for both kinds of spatial evidence, route truth, old-save normalization, DOM wiring, and exact source placement.
