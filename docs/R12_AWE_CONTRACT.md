Selection gates: A is source-safe (only player route), uses actual existing parent geometry and coordinates, requires no invented crew, histories, spatial destinations or extraterrestrial phenomena, supports reduced motion, and preserves gameplay. The incumbent unchanged remains preferable if the spatial trace obscures the empty scene; player controls must allow the trace to disappear.

Design law: **monumental industrial elegy**. Human-scale warm practical lamps and maintenance fittings meet dark cold compressed orbital scale. Deliberate structural subtraction takes priority over VFX volume. Use authored visible change and efficient reuse, never a new visual technology/dependency for decoration. All additions remain explicitly reconstruction artifacts rather than history.

Falsification: a fresh player walks the room, returns to Month Six, and sees an accurate fragment of *their own* route with no invisible floor; a player who did not walk sees no generated route. The small-room survey outline appears only on an explicit user action and does not resurrect collision. The inverse action restores complete absence. Original broad ghost and comparison tools remain available independently.

## Performance experiment contract

Baseline R11 archive; candidate R12 same exact orbit and interior views, 1440x900 or documented alternate, WebGL2, same pixel ratio and normal/economy quality. Record median/p95 frame time from a foreground render loop when possible; `renderer.info` calls / textures / geometries as proxy only. Profile cold ready, Month Zero walk with real crew, Month Zero wide, Month Six former, comparison and four repeat timeline scrubs. Never convert headless rAF throttling into app FPS. Physical touch / thermal proof requires physical device.

Protected behaviors: 74 removable model groups, 12 dock arms, all seven checkpoints, collisions, all input modes, saving, touch, source provenance, witness cut and replay/reverse, physical named dead inert, three unnamed local Rocketbox occupants, no Drakken/Tiger/combat/ghosts and no spiders.
